# Visualizing Minimization of Logical Functions

This project is an AngularJS application designed to help visualize the process of minimizing logical functions. It provides a user-friendly interface to apply various algorithms and see the step-by-step reduction.

## Supported Methods
- Indeterminate Coefficients Method
- Implicative Matrix Method
- Quine-McCluskey Method

## Language
The user interface is in Armenian.

# Install
```
    $ npm i -g bower node-static && bower i
    $ static -p 3333
```

open http://localhost:3333/ from your browser

## How to Use
- Once installed and running (http://localhost:3333/), you'll see the home page.
- Select one of the minimization methods from the navigation bar or the links on the home page.
- Input the logical function you want to minimize according to the prompts for that method.
- Click the "Որոշել" (Solve/Determine) button to see the minimization steps and the result.
